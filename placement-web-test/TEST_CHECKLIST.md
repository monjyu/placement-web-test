# 動作確認チェックリスト

## VS Codeでのローカル確認

- [ ] VS Codeでフォルダを開く。
- [ ] `index.html`をブラウザで開き、説明文が表示される。
- [ ] 参加者IDが空、または同意なしでは開始できない。
- [ ] 10問すべてで4つの配置図が表示される。
- [ ] 未選択では「回答を確定」できない。
- [ ] 問題番号が1/10から10/10まで進む。
- [ ] 右下の現在時刻が更新される。
- [ ] 10問後に終了画面へ移動する。
- [ ] CSVバックアップに10行の回答が入る。

## Googleスプレッドシート連携確認

- [ ] `config.js`のURLをApps ScriptのウェブアプリURLへ変更した。
- [ ] Apps Scriptを「自分として実行」「全員がアクセス可」でデプロイした。
- [ ] テスト回答後、`responses`シートに10行追加される。
- [ ] 同じ送信を再試行しても重複行が作られない。
- [ ] 参加者ID、問題番号、回答、正誤、回答時間が正しい。
- [ ] 別のPCまたはスマートフォンからも送信できる。

## GitHub Pages公開確認

- [ ] 公開URLでCSSとJavaScriptが読み込まれる。
- [ ] シークレットウィンドウでもアクセスできる。
- [ ] QRコードから公開URLを開ける。
- [ ] QRコードがGitHubリポジトリではなくGitHub PagesのURLを指している。
